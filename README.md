# 👤 Face Detection App

This is a real-time Face Detection Application built using Python and OpenCV.

## 🚀 Features
- Detects human faces using Haar Cascade
- Draws rectangle around detected faces
- Shows face detection status (Detected / Not Detected)
- Displays number of faces

## 🛠️ Technologies Used
- Python
- OpenCV

## ▶️ How to Run
1. Install OpenCV:
   pip install opencv-python

2. Run the program:
   python face.py
